# Privacy and Security

This private repository is for workflow documentation, not personal records.

Never commit passwords, passcodes, authentication codes, recovery keys, tokens, private keys, identity documents, financial statements, medical records, private correspondence, or employer/client data.

Use placeholders such as `[personal email]`, `[cloud folder]`, and `[device name]`. If a real file is needed for a local test, keep it outside the repository and record only the sanitized result.

If sensitive information is committed accidentally, stop work. Do not merely delete the current file and assume it is gone; Git history and any remote copies must be handled carefully.
