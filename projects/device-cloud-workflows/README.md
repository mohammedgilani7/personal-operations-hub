# Project: Device and Cloud Workflows

## Goal

Make personal workflows between Windows, iPhone, and cloud services reliable, private, and easy to repeat.

## Problems this project addresses

- A task works on one device but requires too many manual handoffs on another.
- Local storage, backup, and synchronization are sometimes treated as if they are the same thing.
- Account, permission, destination, and privacy boundaries may be unclear.

## Definition of done

One selected workflow has:

- a clear starting point and final result;
- fewer user actions than the current process;
- named device, account, app, and storage boundaries;
- a recovery or rollback path;
- realistic end-to-end verification; and
- no sensitive information stored in this repository.

## First exercise

Map one simple personal workflow, such as moving a non-sensitive test photo or document between a phone and a clearly identified laptop folder. Count the manual steps before recommending automation.

Use [`PROJECT_INSTRUCTIONS.md`](PROJECT_INSTRUCTIONS.md) and [`../../templates/decision-log.md`](../../templates/decision-log.md).
