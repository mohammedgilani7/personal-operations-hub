# Device and Cloud Workflow Instructions

## Start with the workflow

Document:

1. Trigger — what starts the task.
2. Source — device, app, account, and location.
3. Handoffs — every tap, upload, download, copy, or approval.
4. Destination — the literal final location and expected format.
5. Verification — how success will be proven.
6. Recovery — how to undo or resume safely.

## Required rules

- Confirm the exact device and account; never infer identity from a similar name.
- Separate synchronization, backup, archive, and local copy in the plan.
- Use non-sensitive test data first.
- The user enters passwords, passcodes, and authentication codes privately.
- Do not change account security, permissions, subscriptions, cloud synchronization, or backup settings without explicit approval.
- Do not connect personal services to employer systems or data.
- Recommend automation only when it reduces total user work and preserves a review point where needed.

## Verification

Test the workflow from beginning to end using normal user behavior. Confirm the item appears in the correct destination, remains accessible after reopening the app, and did not create an unexpected duplicate or cloud copy.
