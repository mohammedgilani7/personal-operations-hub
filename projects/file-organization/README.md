# Project: File Organization

## Goal

Create a personal file system that makes important items easy to find without unsafe bulk moves or duplicate storage.

## Problems this project addresses

- Files are spread across local folders and multiple cloud services.
- Similar names make ownership, location, or duplication uncertain.
- Reorganizing too quickly can break synchronization or lose the original context.

## Definition of done

A selected folder or file category has:

- one clearly identified source of truth;
- a simple naming and folder rule;
- uncertain and duplicate items preserved for review;
- an approved destination;
- a verified move or copy log; and
- a clear next checkpoint.

## First exercise

Choose one low-risk category, such as personal learning documents. Complete a filename-and-metadata inventory first. Do not start with financial, medical, identity, or employer records.

Use [`PROJECT_INSTRUCTIONS.md`](PROJECT_INSTRUCTIONS.md) for the required workflow and [`../../templates/project-checklist.md`](../../templates/project-checklist.md) to track the work.
