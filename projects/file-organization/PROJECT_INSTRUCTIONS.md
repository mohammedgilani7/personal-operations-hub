# File Organization Instructions

## Before changing files

Record:

- objective;
- exact source path or cloud folder;
- exact destination;
- review depth: filenames only, metadata, readable text, or visual inspection;
- exclusions;
- backup or preservation method; and
- success checks.

## Required rules

- Use literal, verified source and destination paths.
- Keep local, OneDrive, Google Drive, and iCloud locations conceptually separate.
- Do not assume folders with similar names are the same.
- Never overwrite a same-name item automatically.
- Put uncertain items in a clearly labeled review area.
- Treat suspected duplicates as candidates, not confirmed duplicates.
- Preserve exact naming and order decisions once approved.
- Obtain explicit approval before deletion, bulk renaming, or a large move.

## Verification

After an approved move or copy, check:

- source and destination both exist as expected;
- item count and total size are plausible;
- a sample of files opens correctly;
- no unexpected overwrite occurred;
- cloud synchronization status is understood; and
- the remaining review items are listed.
